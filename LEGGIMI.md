# Salute bimbi - installazione
1. Carica questa cartella su un hosting statico gratuito (es. GitHub Pages o Netlify Drop).
2. Apri l'indirizzo in Chrome sul telefono e scegli «Installa app».
I dati restano solo nel localStorage del browser di questo telefono (usa «Backup dati» per salvarne una copia).
Promemoria: sotto ogni farmaco usa «Aggiungi al Calendario» (Google Calendar).
